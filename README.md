# PostoRH - Central Operacional de Gestão de Postos de Combustíveis

Sistema completo de Recursos Humanos e Gestão Operacional para rede de postos de combustíveis.

---

## 🚀 Como Executar Localmente

### Opção 1: Via Node.js (Sem necessidade de instalar pacotes externos)
```bash
node server.js
```
ou
```bash
npm start
```
Após iniciar, acesse no navegador: **[http://localhost:3000](http://localhost:3000)**

---

## 📁 Estrutura de Arquivos Organizada

| Arquivo | Descrição |
| :--- | :--- |
| **`index.html`** / **`dashboard.html`** | Dashboard Operacional & KPIs principais da rede |
| **`colaboradores.html`** | Gestão de Colaboradores, Quadro de Frentistas e Gaveta Lateral de Detalhes |
| **`frequencia.html`** | Gestão de Frequência, Turnos de Pista e Apontamentos Diários |
| **`financeiro-vales.html`** | Gestão Financeira de Pessoal, Lançamento de Adiantamentos e Vales |
| **`mapa-unidades.html`** | Mapa de Geolocalização das Unidades e Postos da Rede |
| **`server.js`** | Servidor local HTTP rápido e sem dependências |
| **`docs/DESIGN.md`** | Especificações de design, paleta corporativa e tokens de tipografia Geist |
| **`screenshots/`** | Imagens originais de referência de cada tela |
